XELO Packet Monitor Documentation

A practical guide to packet capture and Windows network diagnostics with XELO Packet Monitor, a graphical interface built around Microsoft's Pktmon.

Download the application

Overview

XELO Packet Monitor helps administrators capture traffic, set protocol and network component filters, view live counters, convert ETL captures to PCAPNG, and organize investigation sessions without manually composing every Pktmon command.

It is a Windows desktop application, not a cloud-based monitoring service. It invokes the Pktmon version available on the host Windows system. It does not replace Wireshark or a complete packet decoder.

System requirements

  • 64-bit Windows with the Microsoft pktmon.exe utility available.
  • Administrator privileges to perform packet capture; approve the Windows UAC prompt.
  • Enough disk space for captures; the application checks for at least 512 MiB of free space before starting.
  • The public ZIP is self-contained for Windows x64; a separate .NET runtime installation is not normally necessary.

Supported options can differ between Windows versions. XELO checks available Pktmon command help and capabilities rather than assuming every command works everywhere.

Download and install

  1. Open the Packet Monitor product page and download the Windows x64 ZIP.
  2. Optionally download SHA256SUMS.txt to verify the release file.
  3. Extract the ZIP to a folder you control.
  4. Run Xelo.PacketMonitor.exe and approve the administrator prompt.
  5. Check the detected Windows version, Pktmon status and application diagnostics before starting a capture.

Verify the download

Get-FileHash -Algorithm SHA256 ".\XELO-PacketMonitor-v1.0.0-rc.1-win-x64.zip"

Compare the resulting hash to the entry in SHA256SUMS.txt from the same GitHub Release. Version 1.0.0-rc.1 is a prerelease: evaluate it appropriately before depending on it in production.

Your first packet capture

  1. Click Refresh status and ensure another Pktmon capture is not already running. Existing machine-wide filters may also be in place.
  2. Use Browse... to choose the capture output directory. By default, captures are stored under Documents\XELO Packet Monitor\Captures.
  3. Start with NICs only, use Any protocol, and leave IP and port unspecified for a basic test.
  4. Set packet length and logging options to suit your investigation. Full-packet captures may contain sensitive information and grow quickly.
  5. Click Start capture; review any warnings before allowing changes to existing filters.
  6. Reproduce the connectivity issue, inspect counters if useful, then click Stop capture.
  7. If Automatically export PCAPNG when stopped is enabled and the installed Pktmon supports it, the application attempts conversion after capture ends.
  8. Open the Sessions tab to review saved evidence.
Important: Pktmon capture state and filters are machine-wide. Do not overwrite another administrator's capture or filters. An interrupted application does not necessarily stop an underlying Pktmon capture.

Filters and capture presets

Quick filters

The capture configuration offers an optional IP address or CIDR subnet, a port (0 meaning any), and a protocol such as TCP, UDP, ICMP or ICMPv6. Use only filters relevant to the traffic you need to investigate.

Advanced filters

Select Advanced filters... to define multiple packet rules. Criteria within a rule combine together; separate rules offer alternative matches. The application checks installed Pktmon capabilities before applying supported options.

Presets

The Capture preset control includes ready-made examples for RDP (TCP 3389), DNS (TCP and UDP 53), HTTPS (TCP 443), and SMB (TCP 445). You can also save and load your own capture configurations. Saved preset preferences are stored locally for the Windows user.

Note: Selecting a protocol or preset does not guarantee that matching traffic exists or that upstream encrypted traffic can be decoded.

Network component selection

The capture scope can target NICs, all components or explicitly selected component IDs. For explicit selection, click Choose components... and choose a mode:

ModePurpose
SimpleConvenient adapter-oriented selection.
AdvancedSelect components from a more detailed component hierarchy.
ExpertSearch or manually specify component IDs for advanced troubleshooting.

The selector is based on components reported by the installed Pktmon. Changing selection modes may require confirmation if it would clear the current selection.

Sessions, conversion and retention

The Sessions tab groups related capture files and metadata. Where available, it helps identify completed sessions with PCAPNG output, incomplete or interrupted sessions, and legacy captures. It provides options to inspect, open and delete selected sessions, with confirmation for destructive actions.

ETL is the original Pktmon evidence format. PCAPNG enables packet analysis in third-party tools such as Wireshark, but may not preserve all ETL-specific metadata such as component traversal and drop-reason details. Retain the original ETL when evidence matters.

Retention

Select Retention preview to review candidate cleanup operations before confirming deletion. Default retention preferences include 30 days and keeping the newest 10 sessions; automatic cleanup is disabled by default.

If conversion fails, the application reports the problem and retains the original ETL file rather than discarding it.

Monitoring and diagnostics

Use the counters and diagnostics areas to inspect available traffic counters, packet-drop statistics, status messages, command output and capture-session health. The Command Explorer can show Pktmon help and execute commands, but commands that modify system-wide capture or filters require care. Sessions created outside the GUI may not automatically become GUI-managed sessions.

Operational JSONL logs are maintained under %LOCALAPPDATA%\XELO\PacketMonitor\Logs. Diagnostic exports are intended to exclude raw packet payloads, but always inspect diagnostic packages before sharing them with others.

Troubleshooting

IssueWhat to check
Capture will not startRun elevated; verify Pktmon exists, available disk space, machine-wide capture status and command capability.
No packets appearConfirm the target traffic is being generated. Try a broader filter or NIC scope, and inspect installed Pktmon counters.
Another capture is activeCoordinate with its owner. Do not reset or stop an unrelated Pktmon session.
PCAPNG conversion failsKeep the ETL, confirm disk capacity and check whether the installed Pktmon supports the conversion command.
Unexpected interruptionCheck pktmon status in an elevated terminal. The GUI warns about interrupted session metadata but does not automatically reset system-wide state.
Feature or filter unsupportedOpen Command Explorer help and check the installed Pktmon version. Options vary across Windows releases.

Read-only status check

pktmon status

Only stop an existing capture when you have established that it is yours and safe to interrupt.

Privacy, safety and limitations

  • Captured network traffic can contain personal data, session tokens, credentials or application payloads. Store, transmit and delete traces according to your organization's rules.
  • Use captures only on devices and networks you are authorized to inspect.
  • Some capture changes affect Windows globally, including existing Pktmon filters.
  • PCAPNG output is not a complete substitute for raw ETL evidence.
  • Do not upload sensitive capture files or diagnostics to public GitHub issues or repositories.
  • The current release is a prerelease and is not represented as a signed enterprise installer.

Frequently asked questions

Does XELO Packet Monitor include Pktmon?

No. It uses the Pktmon utility provided by the target Windows installation.

Does it need Wireshark?

No, not to perform the capture. Wireshark or another analyzer can be useful to examine exported PCAPNG files.

Does it require internet access to capture packets?

Capture operations run locally through Windows Pktmon. Website and donation links naturally require connectivity when opened.

Is XELO Packet Monitor free?

Yes. Donations are voluntary via Buy Me a Coffee.

Where can I see release history?

See the public XELO Releases page.
