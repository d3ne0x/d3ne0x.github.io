XELO Packet Monitor

Packet capture, live network monitoring and troubleshooting with Microsoft's built-in Pktmon utility in an approachable desktop interface.

v1.0.0-rc.1 · Windows x64 · Free public prerelease · Self-contained ZIP package.

Download XELO Packet Monitor

Release notes · SHA-256 checksum

Extract the ZIP and run Xelo.PacketMonitor.exe. Administrator permission is required for capture operations. Verify integrity with Get-FileHash -Algorithm SHA256 .\XELO-PacketMonitor-v1.0.0-rc.1-win-x64.zip and compare with SHA256SUMS.txt.

Features

  • Capture traffic and convert ETL files into PCAPNG.
  • IP address, port and protocol filtering with reusable presets.
  • Network component selection and live traffic counters.
  • Capture session history, retention previews and diagnostic exports.

Requirements

Windows with Pktmon available and administrator permissions for packet capture operations. Compatibility is checked on the installed Windows version.

About this application

XELO Packet Monitor is a free XELO Labs application for network troubleshooting. It uses Microsoft Pktmon but is not affiliated with Microsoft.
